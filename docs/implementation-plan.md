# 愿TA 本地 Web 基础工程

依据：已确定的暖木邮局桌面视觉设计、修正桌牌后的首页、原始 PRD。当前用户已要求实施，不重新开启设计审批。

技术：React、TypeScript、Vite；独立 CSS 视觉变量；结构化数据和照片统一存 IndexedDB。无服务器、无部署、无云账号。

- [x] 工程与领域模型：04:00 中国时区产品日、七天任务、自然周账本、结算条件、持久化与故障反馈。
- [x] 配套素材：无文字邮局场景、透明底小愿；原稿保持原样，生成提示词与来源另存。
- [x] 页面：横向导航、首页、四步创建（五问可跳过）、今日图片记录、账本、示例愿签池、我的、两幕结算、独立演示数据。
- [x] 验证：类型构建、领域规则测试、浏览器创建与记录流程、刷新恢复、窄屏与主要页面截图。

范围边界：基础工程实现本机闭环。公开池只展示示例，回信仅本地保存。真实 AI、身份认证、跨设备恢复、云同步、审核后台与分享短链需后续服务端。照片和五问不进入公开视图。普通流程不提供提前结算；演示快进和结局切换只出现在独立演示会话。
