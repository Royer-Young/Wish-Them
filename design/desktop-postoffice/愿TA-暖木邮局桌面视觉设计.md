# 愿TA 暖木愿望邮局桌面端视觉设计

日期：2026-11-18  
产品形态：桌面浏览器 Web 应用。  
方向来源：已选定的 A「暖木愿望邮局」。  
交付：四张桌面横屏概念效果图、全站布局与组件规范、女孩微交互规则。本次为视觉设计，尚未实现可操作的网站或逐帧角色动画。

## 视觉定位

把愿TA设计成一间可以办理心意的像素邮局。用户进入温暖的邮局，在自己的书桌前写愿签、记录小事、翻账本、读回信。横向空间用于并排呈现任务和记录、编辑和预览，减少反复切换页面。

延续上一版的奶油纸面、蜂蜜木色、朱红按钮、鼠尾草绿和女孩“小愿”。保持像素场景与纸面工具之间的层次：场景表达温度，纸面表达内容，朱红强调当前最重要的动作。

参考：[已选定视觉方向](../visual-proposals/A-暖木愿望邮局.png)。本文件为当前桌面版依据；上一版竖屏概念保留作视觉探索记录。

## 桌面布局

### 公共框架

基准画布 1440×900，另检查 1280×800、1600×1000 和 1920×1080。常规内容最大宽度 1320，1440 画布时左右各 60；首页和结算的场景可延伸至内容区外，文字和主要操作仍在版心内。

顶部导航高 72，左侧品牌，居中“邮局首页 / 今日 / 愿签池 / 账本 / 我的”，右侧回信通知与个人入口。通知用信封加未读标记；当前栏目同时使用朱红底签和明确的选中样式。创建属于独立子流程，使用步骤导航表达位置。

常规桌面操作不依赖场景物件上的隐形热点。红色信箱可以作为查看回信的第二入口，同时保留有文字的通知入口。

### 首页

一个横向邮局场景占据首屏主体。左约四成放置产品主张、说明与主按钮；右约六成展示柜台、小愿、红色信箱和夕阳水面。底部用简短的“写下心愿 / 做今天的小事 / 把心意带到现实”说明过程。

主按钮固定为“替TA许个愿”；已有进行中愿签时使用“继续今天的小事”。次操作“看看大家的愿望”。首屏提供默认私密说明。

### 创建

内容宽 1320 时，建议列宽为 200 / 728 / 344，列间距 24。

左侧步骤包括选人、写愿望、几个小问题、签下约定。中间为当前输入与操作，右侧同步愿签预览，角色在预览下方。五问保持一屏一问，每题可以跳过，避免把五问变为并排的长问卷。

写愿望最多 120 字。AI 润色显示三条带“AI辅助”标签的建议，点“选用”后才替换原文。底部“上一步 / 下一步”保持固定位置；草稿保存状态可见。

契约页展示每天做什么、完成规则与结算方式。桌面端同时提供鼠标手写和“按住签下约定”两种入口，另提供键盘可用的确认方式。完成后提示恢复码。

### 今日

内容宽 1320 时，建议列宽为 208 / 704 / 360，列间距 24。

左侧显示当前愿签、对象、私密状态与查看愿签入口；下面放中性的关闭问号抽屉。中间显示两张必做任务，为TA和为自己；周末可在下方显示一张可选钱任务。右侧在选择任务后显示记录面板。

今日只展示今天与“已完成 1/2”等当日状态，不显示第几天、总天数或剩余天数。已完成任务使用“查看记录”，待完成任务使用“去记录”。

### 记录

桌面记录面板宽约 360–420。支持点击上传、拖入照片或截图，以及粘贴截图；拖入高亮只在有效图片进入时出现。文字说明明确支持方式，上传区可通过键盘操作。

记录附言最多 30 字。没有图片时不能提交，按钮旁解释“添加照片后即可完成记录”。上传中给出进度与取消，失败保留选图和文字并显示重试。只有真实保存成功后，角色才做完成反馈。

用户使用桌面摄像头时再请求权限；文件上传为默认入口。照片仅自己可见。离线保存与已同步分为不同状态。

### 两幕结算

第一幕以纸面愿签与完成条目为焦点，满足必做完成条件才盖“已还愿”章。约两秒后允许进入第二幕，也可以跳过动画直接看结果。

第二幕展开问号抽屉，右侧出现账本与现实兑现建议，角色递信。示例账本为省下48元、挣到120元，合计168元。礼物及其名称只在第二幕出现。信件可编辑，主按钮“保存心意”，次按钮“分享愿签”。

三档结局分别采用盖章与兑现建议、盖章与未拆信、保留愿签并继续完成的布局。缺钱或漏任务时明确显示差额或待补内容，以及规则允许的续期入口。实际是否已购买、已送达由用户记录，视觉效果不暗示现实行动自动发生。

## 账本、愿签池与其他页面

| 页面 | 桌面结构 | 暖木邮局表达 |
| --- | --- | --- |
| 账本 | 左自然周目录，中收入与支出明细，右本周汇总与记账表单 | 订线账册、纸质分隔签、小票；使用元与真实金额 |
| 记账 | 账本内侧栏或居中表单，关联赚钱任务与佐证 | 小票输入，数字右对齐，计算结果即时可见 |
| 愿签池 | 左分类，中两至三列愿签，右可选的阅读面板 | 窗外水面作为顶部场景带，主体保持稳定卡片列表 |
| 愿签详情与回信 | 左原愿签，右回信列表及80字输入框 | 信件展开；“回一句话”“接力许愿”保留文字按钮 |
| 我的 | 左进行中与归档分类，中愿签列表，右选中愿签预览 | 私人信件架；归档状态用印章和文字双重表达 |
| 通知 | 按时间分组的回信与系统消息，点开可读信 | 通知信封，未读状态明确 |
| 设置与恢复 | 左设置目录，右表单，恢复码单独纸卡 | 沿用纸面与描边，输入信息保持平整清晰 |
| 分享链接 | 以愿签与信件为主的独立阅读页面，带“我也许一个” | 保留小标识与小愿，公开内容不含问答、照片及账本 |
| 演示 | 仅演示会话显示进度引导和快进条 | 浮于正常页面边缘，不改变真实用户的导航 |
| 审核后台 | 表格、筛选、详情、审核操作 | 共用字体和色彩，减少场景与角色占用 |

## 色彩与材质

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 奶油纸 | #FFF1C8 | 主背景、纸签 |
| 浅色纸面 | #FFFAED | 表单、长信、明细 |
| 蜂蜜木 | #C88B46 | 桌面、窗框与边缘装饰 |
| 朱砂红 | #B94735 | 主按钮、当前步骤、结算印章 |
| 鼠尾草绿 | #607254 | 已完成、次级标签、小面积植物 |
| 墨棕 | #392B27 | 正文、图标与像素描边 |

正文墨棕在奶油纸上约12.05:1，奶油纸色文字在朱砂红上约4.65:1，奶油纸色文字在鼠尾草绿上约4.63:1。以上为纯色组合计算结果；纹理、透明度和各个状态需在精稿中单独检查。

木纹只放在框架和场景，正文底下不叠纹理。2像素阶梯边角、深棕边线和少量偏移阴影组成统一的纸面组件。大场景层次丰富，细小控件减少装饰。

## 字体与信息层级

- 品牌与少量页面标题使用中文像素字形或单独设计的字标；具体字体选定时核实完整中文覆盖与使用授权。
- 正文使用清晰的中文无衬线字体和系统回退；账本使用等宽数字或等宽数字特性，金额右对齐。
- 首页主标题建议40–48；常规页标题28–32；分组标题20–24；正文16；说明14；状态标签12–14。正文行高约1.6。
- 长信阅读宽度约560–680，避免跨越整个宽屏。字号随系统缩放保持可读，文本区域允许自然增高。

## 组件状态

| 组件 | 默认 | 鼠标经过与聚焦 | 操作后或异常 |
| --- | --- | --- | --- |
| 主按钮 | 朱红底、奶油字、2像素边 | 描边加深；键盘聚焦有独立轮廓 | 按下时自身阴影缩短；忙碌态说明动作 |
| 次按钮 | 奶油底、墨棕字 | 边线加深 | 不改变文字位置与周围布局 |
| 关系标签 | 纸标签 | 提供轮廓反馈 | 朱红底并加勾，使用单选语义 |
| 任务卡 | 分类签、动作、状态、入口 | 明确展示可选区域 | 已完成使用绿勾及“查看记录” |
| 输入框 | 平整浅纸面、可见标签 | 聚焦加朱红细轮廓 | 具体错误放在字段旁，保留原输入 |
| 上传区 | 相机图标、操作文字、支持说明 | 有效图片拖入后高亮 | 上传、失败、本机保存、已同步各有文字 |
| 通知 | 信封与未读标记 | 显示文字名称 | 看完可清除未读状态 |
| 问号抽屉 | 小型关闭木抽屉 | 显示“到期后开启”等解释 | 结算第二幕才展开并展示礼物 |

## 小愿的桌面互动

固定造型：栗棕短发和两条短辫、信封发夹、奶油衬衫、砖红背带裙、棕鞋、小邮差包。沿用已选定的女孩，页面间保持同一张脸与轮廓。

角色在首页约160–220逻辑像素高；工具页通常96–144；结算页约144–192。角色位于页面有目的的位置，例如预览下方、当前愿签旁或信件边。常驻工具页角色可收起，聊天提示可关闭。

| 场景 | 动作 | 反馈 |
| --- | --- | --- |
| 初次到邮局 | 招手一次 | 随后转为低频眨眼 |
| 正在写愿望 | 拿信封安静等待 | 不按每次敲键盘反复弹话 |
| 用户请求AI建议 | 翻便笺或托腮 | 有文字加载状态；失败可回退模板 |
| 记录保存成功 | 点头、写下一笔 | 约500–800毫秒，流程无需等待 |
| 错过任务 | 把纸签留在桌上，递铅笔 | 明确补卡或继续入口 |
| 第一幕 | 盖章 | 只在产品完成条件满足后触发 |
| 第二幕 | 从邮包递信 | 腾出空间读信与操作 |
| 新回信 | 信封轻抬一次 | 未读标记承担持续提醒 |

后续制作角色时提供透明底母版、固定锚点、前侧背视图和逐帧状态。场景和精灵采用整数倍最近邻缩放，文字与交互组件独立排版。

## 桌面交互与适配

- 鼠标经过只补充反馈，主功能都有可见按钮。键盘Tab顺序与视觉顺序一致，聚焦轮廓不被木框和阴影遮挡。
- 对话框支持Esc退出并回到触发按钮；关键删除需要明确确认；侧栏关闭不清空未保存草稿。
- 主按钮建议高44–48，输入框高44，主要点击区域至少44×44；文本链接与次操作保留适当间距。
- 1280以下优先收起当前愿签侧栏；任务和记录保持足够宽度，记录面板可改为覆盖侧栏。窄屏进一步按内容顺序重排，避免整页横向滚动。
- 200%缩放时导航和栏目可以换行或收起，长信和表单保持可用。展示宽屏不意味着固定页面高度，内容增加时允许纵向滚动。
- 按钮反馈80–150毫秒；面板进入160–240毫秒；角色庆祝500–800毫秒。减少动效时保留静态姿态、状态文字和即时结果。
- 环境音默认关闭；小愿不能遮住输入、上传、提交或阅读内容。隐藏标签页暂停环境与角色动画。
- 私密、公开和分享是独立明确的操作状态。账本、照片和五问答案不出现在分享图或公开愿签中。
- 动画负责反馈，真实文本和组件承担输入、状态与信息展示。
