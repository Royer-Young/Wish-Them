# 愿TA 像素风视觉提案

> 当前产品已明确为桌面端 Web，并选定 A「暖木愿望邮局」。后续设计以 [暖木邮局桌面视觉设计](../desktop-postoffice/愿TA-暖木邮局桌面视觉设计.md) 为准；本文件保留早期竖屏视觉探索记录。

日期：2026-11-18  
交付范围：三套视觉概念、每套六个核心页面效果图与女孩吉祥物探索、全部页面的视觉映射、微交互与落地规范。效果图用于选择方向；尚未制作交互原型或可直接使用的动画精灵图。

## 设计出发点

让用户像走进一间温柔的像素小屋，完成几件现实中的小事。场景、人物与反馈带来游戏感，清晰的表单、任务卡和按钮保证工具效率。

参考截图提取四个特征：暖色环境光；有生活细节的室内场景；深色描边与阶梯轮廓；表情清楚、头身比夸张的像素女孩。保留这些视觉语言，另行设计人物、服装和场景。

需求依据：[产品需求文档](../../愿TA_PRD(1).pdf)。文档产品形态为 Web + PWA，本次按用户要求设计为适合微信小程序的竖屏视觉；平台适配、技术选型另行确定。

## 三套方向比较

| 方向 | 感受 | 场景与视觉隐喻 | 使用体验 | 主要成本 |
| --- | --- | --- | --- | --- |
| A 暖木愿望邮局 | 温暖、怀旧、有生活气息 | 愿签是信，记录是投递，结算是盖章与拆信 | 与截图最接近，情感表达自然 | 木纹、信件和室内物件较多，需要控制装饰密度 |
| B 月色星灯小屋 | 安静、梦幻、陪伴 | 每次行动点亮一盏灯，最后打开灯下的信 | RPG 菜单感最强，晚间氛围突出 | 夜色场景与浅色内容面板需要分别校准对比度 |
| C 薄荷晴日庭院 | 清爽、轻盈、日常 | 以植物的细微生长表现被照料的心意 | 文字与操作最突出，适合频繁打开 | 需靠角色与少量精致场景保持像素辨识度 |

推荐以 A 为品牌主方向，采用 C 的内容留白与卡片密度。首页和结算使用丰富场景；今日、记录和账本使用安静的纸面。三套是候选方向，选定后统一角色、颜色与组件。

## A 暖木愿望邮局

### 视觉

奶油色纸张、蜂蜜木色家具、朱红主按钮、鼠尾草绿点缀。邮局窗外有一小段漂着愿签的水面；室内有桌灯、信箱、信件架。文字内容放在平整纸面上，避免木纹穿过正文。

| 色彩用途 | 色值 |
| --- | --- |
| 纸面 | #FFF1C8 |
| 木色场景 | #C88B46 |
| 主操作与印章 | #B94735 |
| 辅助植物与完成状态 | #607254 |
| 正文与描边 | #392B27 |

### 女孩 小愿

栗棕短发，耳侧两条短辫，信封形金色发夹；奶油色衬衫、砖红背带裙、棕色鞋和小邮差包。轮廓识别点是短辫、信封发夹和斜挎包。她的定位是可靠、略有点害羞的愿望邮差。

首页站在柜台旁招手；创建页递纸签；记录页翻开便笺；成功时轻轻盖章；彩蛋页从邮包取出信。角色语言示例：“这句话，我替你收好了。”

### 页面延展

关系选择是收信人标签，愿望输入是信纸，契约是折页，今日任务是木板上的便笺，账本是订线小册，公开池是水边漂信，回信是拆开的小信封。我的页使用个人信件架，恢复码放入明确标注的“恢复码”纸卡。

## B 月色星灯小屋

### 视觉

深靛夜色包围奶油纸面，以浅薰衣草色描边、月金色按钮形成对比。房间里有夜窗、纸灯和水面倒影。大部分正文仍放在浅色面板上，适合细读。

| 色彩用途 | 色值 |
| --- | --- |
| 夜色场景 | #242B49 |
| 轻装饰 | #B5A5DE |
| 内容面板 | #FFF4DA |
| 主按钮与灯光 | #E0BC68 |
| 水面与次级装饰 | #7896AD |

### 女孩 小灯

深靛色长发梳成单侧大辫，月牙发夹；浅紫长袖上衣、米白裙、短披肩与深色靴子，手持方形星灯。轮廓识别点是单侧长辫、短披肩和纸灯。她安静、专注，回应短而克制。

首页坐在窗边；思考时抬头看灯；记录后灯芯亮一下；结算时将灯放到桌上，打开抽屉里的信。角色语言示例：“今天这一点心意，已经亮起来了。”

### 页面延展

关系选择像星灯标签，愿签像窗边悬纸，任务是灯下便笺，账本是抽屉里的小册，公开池是夜湖漂签，回信是窗边信笺。我的页为私人书架。星灯变化承担装饰反馈，不新增星币、战斗数值或升级任务。

## C 薄荷晴日庭院

### 视觉

燕麦白大面积留白，叶绿色主按钮，薄荷色面板，杏桃色作小面积强调。场景是晴天庭院、窗台与温室一角，植物集中在内容边缘。

| 色彩用途 | 色值 |
| --- | --- |
| 主背景 | #FFF9ED |
| 叶片与次级面板 | #779D83 |
| 正文与主按钮 | #284F42 |
| 温暖点缀 | #E9B18C |
| 水面与天空 | #B8D8DB |

### 女孩 小芽

深棕双低丸子头，两片叶子发夹；杏色短袖、鼠尾草绿背带裤、米色袜子和帆布鞋，随身带笔记本。轮廓识别点是双丸子、叶夹和背带裤。她轻快、有耐心，像一起做事的朋友。

首页在桌旁写便笺；创建时举起小纸签；记录时用铅笔打勾；任务完成后窗台植物多一片叶子；结算时打开纸包。角色语言示例：“先做这一件，就很好。”

### 页面延展

关系选择是纸标签，愿望是植物旁的便笺，任务是叶夹纸卡，账本是方格记录本，公开池是庭院水池，回信是压着一片叶子的信。我的页为私人记录夹。植物变化仅为视觉反馈，不额外要求浇水或养成操作。

## 全部界面覆盖

三张概念板各展示：首页、创建愿签、今日、记录、账本、两幕结算。下表定义其余页面的延展，避免只设计首页而遗漏工具流程。

| 界面 | 内容与布局 | 吉祥物与像素表达 |
| --- | --- | --- |
| 首次进入与恢复 | 匿名开始；恢复码说明；输入恢复码找回 | 角色递来身份纸卡，输入框保持清楚 |
| 首页 | 一句产品介绍、示例愿签、开始或继续、浏览愿签池 | 上半部场景、水面漂签，主操作直接可见 |
| 选择关系 | 12 种关系；单选；自定义称呼与代词 | 小头像与像素标签，选中有勾选与描边 |
| 写愿望 | 模板、换一批、自定义 120 字、可选 AI 润色 | 信纸输入，AI 建议保留“AI辅助”标签 |
| 五问 | 一屏一问；步骤、输入与跳过；解释用途 | 小对话头像；说明答案只用于任务建议、不会随愿签分享 |
| 契约与签字 | 每天做什么、完成与结算规则、默认 7 天、签字 | 纸面契约；长按或手写提供明确完成反馈 |
| 愿签生成与恢复提示 | 愿签预览、保存恢复码、去做今天的小事 | 收好纸签，提示可再次查看恢复码 |
| 今日 | 为 TA 和为自己两张必做；周末可出现钱任务 | 角色占小角落；只显示今天，不显示总天数或倒计时 |
| 任务详情与拍照记录 | 任务动作、照片或截图、选填一句话、提交 | 相片槽与纸夹；清楚标明照片私密 |
| 上传与离线 | 上传进度、已保存本机、等待同步、重试 | 正在整理便笺的小动作；上传真实完成后才庆祝 |
| 补卡 | 错过记录、补卡券数量、可补对象、确认 | 中性提示与继续入口，避免扣分感 |
| 账本 | 自然周、省下、挣到、合计、目标差额、记一笔 | 纸面账本；问号关闭，礼物名称与图标尚不展示 |
| 记账与收入关联 | 预算、支出、赚钱任务关联、佐证 | 清晰数字输入和小票卡片，金额属于真实账本 |
| 结算第一幕 | 逐条亮灯，全部必做完成后盖“已还愿”章 | 角色盖章；约两秒后可进入下一幕 |
| 结算第二幕 | 金色问号展开、金额汇总、兑现建议与信 | 原本关闭的物件打开，女孩递信 |
| 兑现卡与信 | 物品参考区间、查一查、信件编辑、保存 | 纸面插画；仅结算后出现礼物；金额不作正好买到的保证 |
| 三档结局与续期 | 双重兑现、赛博实现、继续完成；续期规则 | 分别采用递礼、留信、陪伴动作；文案解释下一步 |
| 愿签池 | 最新与分类、简短愿签、回信入口 | 保留水面与漂签主题；列表模式可稳定浏览 |
| 愿签详情与回信 | 脱敏内容、80 字回信、接力、举报与屏蔽 | 读信与写回信；仅展示授权公开内容 |
| 分享页与分享图 | 只读愿签、一段话、我也许一个；竖版分享图 | 干净纸面与小角色，照片、问答及账本不进入分享 |
| 我的与归档 | 进行中、已还愿、私密记录、设置入口 | 各方向的个人纸签收纳区 |
| 通知与设置 | 回信通知、免打扰、减少动效、恢复与账号设置 | 小信封图标，功能标签使用直白名称 |
| 空白、错误与删除确认 | 保留输入、解释错误、重试或返回 | 角色姿态保持平静；错误与成功有文字提示 |
| 演示与静态兜底 | 六步引导、快进与三结局回放 | 仅演示会话出现操作条，真实界面不展示快进入口 |
| 后台 | 审核队列、举报、模板与记录 | 使用清楚的数据表格，与品牌共用色彩；控制角色装饰 |

## 吉祥物微交互

三名角色为同一吉祥物的不同候选设计。每套在自己的页面中保持发型、服装、比例和描边一致。下面是后续制作动画时的状态清单；概念板中的六种姿势是造型探索，尚非逐帧动画资产。

| 状态 | 触发 | 动作建议 | 反馈与限制 |
| --- | --- | --- | --- |
| 待机 | 页面停留 | 偶尔眨眼、轻呼吸 | 低频；离开屏幕后停止 |
| 招手 | 首次进入或新的一次访问 | 小幅挥手 | 每次进入至多一次，随后回到待机 |
| 思考 | 用户主动请求 AI 建议 | 托腮、翻便笺 | 与“正在整理建议”文字并行，可跳过 |
| 倾听 | 关系与五问选择 | 点头或侧头 | 不读取用户未提交的内容来制造反应 |
| 记录 | 本机保存或上传中 | 写字、夹照片 | 区分“本机保存”与“已同步” |
| 开心 | 记录提交成功 | 一个小跳、两三颗像素亮点 | 约 500–800ms，随后收起 |
| 陪伴 | 错过任务、钱未攒够 | 坐在纸签旁，递来铅笔 | 提示补做或续期，语气温和 |
| 盖章 | 第一幕满足完成条件 | 抬手、落章、轻震一下 | 可跳过；减少动效时直接显示结果 |
| 递信 | 第二幕开启或收到回信 | 拿出并递出信封 | 留出信件正文阅读空间 |

点角色可显示一条短提示；提示同时提供关闭按钮。角色不遮挡输入框、相机、提交按钮或微信右上角胶囊。静音与减少动效作为独立设置，关键流程无需等动画播放完。

## 像素与可用性规范

- 设计基准宽度 375 逻辑像素，内容左右留白建议 16–20，卡片间距 12–16；正文建议 16，辅助文字 12–14，主要按钮高 48。
- 中文正文、账本数字、长信件使用清晰的常规字体。像素字用于品牌标题和短标签；中文覆盖与字体授权需在选定字体时核实。
- 常规操作采用 2 像素阶梯描边、少量 2–4 像素偏移阴影。场景有纹理，阅读面板保持平整。
- 角色母版建议以 96×96 像素统一格制作，按整数倍显示；小头像、主场景与表情使用同一色板和描边体系。
- 后续素材需提供透明 PNG、统一锚点、固定画布与状态命名。先锁定正面、侧面、背面与主要表情，再制作各动作的逐帧序列。
- 图像按最近邻方式缩放，保留阶梯边缘；布局容器可随屏幕宽度适配。绘制精灵与真实设备像素密度分开处理。
- 文本目标对比度不低于 4.5:1；选中、完成、错过等状态同时有文字或形状反馈。候选色值需在组件成稿后逐一测量。
- 主导航保持“今日 / 愿签池 / 账本 / 我的”四项。界面可展示邮局、星灯或庭院隐喻，按钮仍用“去记录”“记一笔”“分享愿签”等明确名称。
- 实际点击区至少 44×44；小精灵和小图标可有透明扩展点击区。保留顶部胶囊、底部手势区和键盘弹出后的空间。
- 按钮按下反馈约 80–150ms，面板过渡约 160–240ms。重要内容即时可读，庆祝动画异步播放，并提供减少动效。
- 默认私密；问答、账本、照片不进入公开或分享内容。AI 建议保持标签，由用户选择后写入。
- 今日不显示旅程倒计时；礼物只在结算第二幕揭晓；完成反馈以真实保存状态为准。
